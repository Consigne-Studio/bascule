Bascule : composants tiers
==========================

Le paquet de l'outil Bascule (dotnet tool) contient les composants suivants. Le code de Bascule lui-même
est sous licence MIT pour l'édition gratuite (fichier LICENSE) et sous licence commerciale pour l'édition Pro.

1. Roslyn : Microsoft.CodeAnalysis et Microsoft.CodeAnalysis.CSharp 5.3.0, avec System.Collections.Immutable
   et System.Reflection.Metadata
   Copyright (c) .NET Foundation and Contributors. Licence MIT.
   https://github.com/dotnet/roslyn

2. Selenium.WebDriver et Selenium.Support 4.51.0 (bibliothèques seules, sans Selenium Manager)
   Copyright 2011-2026 Software Freedom Conservancy. Licence Apache 2.0.
   https://github.com/SeleniumHQ/selenium
   Bascule ne les exécute pas : il en lit les métadonnées pour reconnaître l'API dans le code analysé.

3. DotNetSeleniumExtras.WaitHelpers 3.11.0 et DotNetSeleniumExtras.PageObjects.Core 4.48.0
   Copyright Software Freedom Conservancy et contributeurs de DotNetSeleniumExtras. Licence Apache 2.0.
   https://github.com/DotNetSeleniumTools/DotNetSeleniumExtras
   https://github.com/Dreamescaper/DotNetSeleniumExtras
   Mêmes conditions d'usage que le point 2.

4. Polices intégrées au rapport HTML : Archivo, Martian Mono, Atkinson Hyperlegible Next
   Licence SIL Open Font License 1.1 (src/Bascule.Noyau/Rapport/Ressources/OFL.txt, reproduite dans le paquet sous le nom LICENCE-POLICES.txt).

Le texte de la licence Apache 2.0 est disponible à l'adresse https://www.apache.org/licenses/LICENSE-2.0
et figure dans les paquets NuGet d'origine. Aucune modification n'a été apportée à ces composants.
