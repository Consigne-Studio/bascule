Avant de migrer vers Playwright, mesurez.

Bascule lit une suite de tests Selenium C# avec Roslyn et dit, fichier par fichier, ce qui se convertit tout seul, ce qui sera à relire et ce qui restera à reprendre. Hors ligne, sans compiler ni exécuter la suite.

Installer et lancer

SDK .NET 8 ou plus récent · Windows, macOS, Linux
# dans le dossier où vous avez téléchargé Bascule.1.0.0.nupkg
dotnet tool install --global Bascule \
    --version 1.0.0 --add-source .

# dossier, .sln, .slnx ou .csproj
bascule diagnostic MaSuite.sln
bascule diagnostic ./tests/Projet.Tests --rapport ./audit

Ou depuis les sources : dotnet run --project src/Bascule -c Release -- diagnostic <chemin>. Empreinte du paquet dans SHA256SUMS.txt, à côté du téléchargement.

  • Cadres : NUnit 3 et 4, MSTest 2 et 3, xUnit 2 ; scénarios Reqnroll et SpecFlow comptés.
  • Selenium 3 et 4, SeleniumExtras (attentes, [FindsBy]), WebDriverManager.
  • Projets .NET Core 3.1 à .NET 10 et .NET Framework 4.6.2 et plus ; l'ancien format est signalé.
  • Rien n'est envoyé : aucun appel réseau ; la suite n'a pas besoin de compiler ni d'être restaurée.
  • Sorties : bascule-rapport.html (autonome, imprimable) et bascule-rapport.json.

Ce que dit le rapport

Trois niveaux, avec l'emplacement exact
Automatique

Ce que la migration réécrira sans changement de comportement attendu : sélecteurs, actions, lectures, attentes, cadres, alertes, cookies, scripts, assertions.

À relire

Converti, mais à vérifier : pause fixe gardée, couleur lue en rgb(), envoi de fichier, élément périmé.

À reprendre

Sans équivalent automatique : fenêtres par identifiant, script asynchrone, grille distante, Appium, cadre traversé par un utilitaire.

Le travail restant est estimé à 20 minutes par point à reprendre (5 quand il se répète dans le même fichier), 4 par point à relire et 1 par test pour la vérification : un ordre de grandeur, pas un devis.

Le JSON reprend les mêmes données, pour un tableau de bord ou pour suivre la migration dans le temps.
